Vice Cover Studio turns your photos into a GTA-style multi-panel poster cover: 6 collage layouts, 5 sunset/neon colour grades, per-panel crop and place labels, giant 3D gradient title lettering, and one-click PNG export in square, portrait and landscape post sizes. Everything runs offline in the browser; photos never leave your machine.
## Run it
```sh
node serve.ts
```
Then open http://localhost:8080 in desktop Chrome.
