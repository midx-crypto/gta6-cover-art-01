NEON PALMS is a Leonida cover studio that turns your own photos into a GTA-style multi-panel cover: one tall hero portrait beside a 2×2 photo grid, a big 3D gradient title overlapping the seam, WANTED stars, a starburst seal, a barcode and a billing block, exported as a PNG in 1080×1080, 1080×1350 or 1920×1080. Six layouts, five colour grades, per-panel drag, zoom, flip, swap and face focus, plus Paint, Grade, Halftone, Grain and Glow sliders. Everything runs offline in the browser from static files; photos are read on your own machine and never uploaded. Original art only: no Rockstar logos, artwork or fonts. Anton and Pacifico ship under the SIL Open Font License.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Add your photos, pick a layout and grade, edit the caption, and export all three sizes. To hand the entry in, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`; to retake its screenshots, run `node shots-r5.mjs`.
